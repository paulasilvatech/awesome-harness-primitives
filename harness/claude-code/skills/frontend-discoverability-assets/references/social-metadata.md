# Social metadata

Open Graph baseline:

- `og:title`
- `og:type`
- `og:url`
- `og:image`
- useful `og:description`
- `og:image:alt` and accurate image metadata when an image is present

Use visible public content, stable absolute deployed URLs, readable contrast, safe text margins, correct branding, and no user-specific or sensitive data.

Add consumer-specific metadata only when the target service's current official documentation requires behavior not covered by shared metadata. Preview caches and image requirements vary; record the service, date, environment, and manual validation result.

Source: https://ogp.me/
