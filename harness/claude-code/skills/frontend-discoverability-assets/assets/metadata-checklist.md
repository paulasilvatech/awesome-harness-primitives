# Metadata and asset checklist

- [ ] Route is classified as public canonical, alternate, private, sensitive, preview, error, redirect, or not applicable.
- [ ] Rendered title and description are unique, descriptive, and match visible content.
- [ ] Canonical and locale alternates are stable absolute URLs.
- [ ] Status, redirects, links, robots policy, and sitemap behavior match the environment.
- [ ] Structured data uses a supported type and matches visible content.
- [ ] Open Graph baseline and image alternative text are complete when sharing applies.
- [ ] Preview assets contain no personal, secret, or user-specific data.
- [ ] SVG master exists and each bitmap or native derivative has a documented target.
- [ ] Declared icon sizes match actual resources.
- [ ] Manifest fields match real scope, start URL, display mode, colors, and icons.
- [ ] Automated rendered-output checks ran.
- [ ] Manual search, preview, installability, or store checks are recorded separately.
