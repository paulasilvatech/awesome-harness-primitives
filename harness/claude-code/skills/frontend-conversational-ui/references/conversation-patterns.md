# Conversation patterns

| Area | Required decisions |
| --- | --- |
| Entry | New versus existing thread, prompt suggestions, empty state, model/tool availability |
| Composer | Multiline, send shortcut, attachments, recording, limits, disabled/offline, draft retention |
| Messages | Identity, timestamps when useful, edit/delete, copy, code, tables, citations, feedback |
| History | Title, rename, search, archive, deletion, retention, synchronization, access |
| Long output | Progressive rendering, anchors, headings, selection, copy, stop, resume, reduced updates |
| Errors | User input retention, partial response, retry consequence, auth/access, rate limit, unavailable |
| Privacy | Data-use disclosure, sensitive input warning when approved, retention and deletion behavior |

Avoid decorative typing indicators that obscure actual pending, tool, or network state.
