# Mobile testing

- Start: install, first launch, cold/warm start, session restore, migration, update.
- Lifecycle: background, foreground, termination, memory pressure, interrupted network, resumed task.
- Navigation: back behavior, deep link, universal/app link, notification entry, expired route access.
- Input: touch, keyboard, hardware keyboard, rotation, safe areas, dynamic type, gesture alternatives.
- Permissions: not determined, allowed, denied, restricted, revoked, settings return.
- Data: offline, queue, sync, conflict, duplicate action, stale cache, partial failure.
- Accessibility: VoiceOver/TalkBack, traversal, labels, actions, announcements, focus, scaling, contrast, reduced motion.
- Runtime: startup, memory, battery, frames, large lists, media and native bridge.

Use real devices for risks that simulators or emulators cannot represent.
