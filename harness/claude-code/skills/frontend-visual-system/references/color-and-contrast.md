# Semantic color and contrast

Define roles before values:

- canvas, surface, elevated surface, text, muted text, border, and overlay;
- action, hover, active, selected, disabled, and focus;
- success, warning, danger, information, and neutral status;
- chart series, comparison, selection, threshold, missing, delayed, and unavailable data.

For every role, verify light and dark themes when supported, text and non-text contrast, color-independent meaning, forced colors, high contrast, and disabled-state legibility. Do not describe an automated contrast scan as complete accessibility proof.
