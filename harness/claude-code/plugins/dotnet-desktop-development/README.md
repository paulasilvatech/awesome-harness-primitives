# Dotnet Desktop Development Plugin

Build Windows and cross-platform .NET client applications with the MVVM Toolkit, dependency injection, messaging, Windows metadata APIs, WinUI 3 migration, Microsoft Store publishing, System.CommandLine, NuGet, and timezone handling.

## Installation

```bash
copilot plugin install dotnet-desktop-development@copilot-primitives
```

## What's Included

### Agents

| Agent | Description |
|-------|-------------|
| `dotnet-maui` | Support .NET MAUI cross-platform apps with controls, XAML, handlers, performance, and navigation guidance. |
| `winforms-expert` | Support development of .NET (OOP) WinForms Designer compatible Apps. |

### Skills

| Command | Description |
|---------|-------------|
| `/dotnet-desktop-development:dotnet-timezone` | Resolve .NET and C# timezone questions with TimeZoneInfo, DateTimeOffset, TimeZoneConverter, NodaTime, UTC conversion, daylight saving time, scheduling, Windows and IANA timezone IDs, location lookup, and copy-paste-ready code. |
| `/dotnet-desktop-development:msstore-cli` | Use Microsoft Store Developer CLI (msstore) to configure Partner Center credentials, list Store apps, package and publish Windows submissions, check status, manage package flights, gradual rollouts, and CI/CD publishing for Windows App SDK/WinUI, UWP, .NET MAUI, Flutter, Electron, React Native, and PWA apps. |
| `/dotnet-desktop-development:mvvm-toolkit` | CommunityToolkit.Mvvm core guidance for ViewModels, source generators, observable properties, commands, validation, and base-class selection. |
| `/dotnet-desktop-development:mvvm-toolkit-di` | Wire CommunityToolkit.Mvvm ViewModels into Microsoft.Extensions.DependencyInjection for XAML apps. |
| `/dotnet-desktop-development:mvvm-toolkit-messenger` | Configure CommunityToolkit.Mvvm Messenger pub/sub for decoupled ViewModel communication. |
| `/dotnet-desktop-development:nuget-manager` | Manage NuGet packages safely in .NET projects and solutions using the `dotnet` CLI. |
| `/dotnet-desktop-development:system-commandline-cli` | Add, modify, or review .NET CLI commands built with System.CommandLine by applying project command-base conventions, options and arguments, SetAction handlers, RootCommand registration, global options, dependency injection, validation, naming, and destructive-operation confirmation. |
| `/dotnet-desktop-development:winmd-api-search` | Find and explore Windows desktop APIs. |
| `/dotnet-desktop-development:winui3-migration-guide` | Maps UWP APIs and patterns to WinUI 3 and Windows App SDK equivalents with migration rules for namespaces, threading, windowing, dialogs, pickers, sharing, printing, background tasks, settings, tests, and common GitHub Copilot mistakes. |
