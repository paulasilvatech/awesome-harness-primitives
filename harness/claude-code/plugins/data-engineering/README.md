# Data Engineering Plugin

Engineer and audit data systems: BigQuery pipeline cost and safety audits, Snowflake semantic views, SQL Server reconciliation and Oracle migration tooling, credit-risk data preparation, Kusto analytics, and Pinecone vector pipelines.

## Installation

```bash
copilot plugin install data-engineering@copilot-primitives
```

## What's Included

### Agents

| Agent | Description |
|-------|-------------|
| `defender-scout-kql` | Generates, validates, optimizes, and explains Microsoft Defender XDR Advanced Hunting KQL. Use for Endpoint, Identity, Office 365, Cloud Apps, alerts, email, and vulnerability queries. |
| `kusto-assistant` | Expert KQL assistant for live Azure Data Explorer analysis via Azure MCP server. |

### Skills

| Command | Description |
|---------|-------------|
| `/data-engineering:bigquery-pipeline-audit` | Audit Python and BigQuery pipeline scripts for cost exposure, dry-run safety, bounded backfills, query pruning, idempotent writes, and observability. |
| `/data-engineering:datanalysis-credit-risk` | Run and explain a credit risk data cleaning and variable screening pipeline for pre-loan modeling, including missing value analysis, abnormal period filtering, high-missing removal, low-IV filtering, high-PSI filtering, Null Importance denoising, high-correlation removal, organization-level analysis, OOS separation, and Excel report generation. |
| `/data-engineering:pinecone-rag` | Build production RAG pipelines and persistent agent memory with Pinecone as the vector database backend. |
| `/data-engineering:snowflake-semanticview` | Create, alter, validate, and troubleshoot Snowflake semantic views with Snowflake CLI. |
| `/data-engineering:sql-server-table-reconciliation` | Compare SQL Server tables across source and target instances for migration validation, ETL verification, production versus staging checks, schema drift, missing rows, extra rows, and column mismatches. |
| `/data-engineering:ssma-console` | Generate XML configuration and execute Microsoft SQL Server Migration Assistant for Oracle console operations without wrapper scripts. |
