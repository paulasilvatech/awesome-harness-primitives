# Frontend traceability matrix

| Story ID | Acceptance ID | Scenario ID | Risk | Surface/environment | Test layer | Test or manual procedure | Result | Evidence | Limitation / defect |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

Allowed result states are `pass`, `fail`, `manual`, `not-applicable`, and `blocked`.

Each `not-applicable` result requires evidence. Each `manual` result requires a documented procedure and outcome. Each `blocked` or `fail` result requires an owner and retest condition.
