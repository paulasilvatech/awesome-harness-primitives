# Responsive adaptation human review

Use `pass`, `needs revision`, `blocked`, or `not applicable`.

| Check | Status | Evidence / revision |
| --- | --- | --- |
| Primary task and critical controls remain available in every required profile. |  |  |
| Hierarchy, content, navigation, and controls change deliberately at real transitions. |  |  |
| Tables, charts, toolbars, media, and dense workflows have explicit narrow behavior. |  |  |
| Keyboard, touch, pointer, virtual keyboard, orientation, and safe areas are covered when applicable. |  |  |
| Long content, localization, RTL, zoom, dynamic type, reduced motion, and contrast modes remain usable. |  |  |
| Boundary viewports immediately before and after transitions have runtime evidence or an explicit gap. |  |  |
