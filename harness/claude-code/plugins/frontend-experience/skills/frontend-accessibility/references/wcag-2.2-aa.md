# WCAG 2.2 AA inspection map

Use the normative [WCAG 2.2 Recommendation](https://www.w3.org/TR/WCAG22/) for exact criteria and conformance language. Use the [WAI-ARIA Authoring Practices Guide](https://www.w3.org/WAI/ARIA/apg/) as non-normative design-pattern and keyboard guidance.

| Principle | Frontend evidence |
| --- | --- |
| Perceivable | Alternatives, adaptable structure, captions/transcripts, contrast, zoom/reflow, color-independent meaning |
| Operable | Keyboard completion, focus visibility and non-obscuration, timing, motion safety, navigation, target size, drag alternatives |
| Understandable | Language, predictable controls, instructions, errors, consistent help, reduced redundant entry, accessible authentication |
| Robust | Valid semantics, role/name/value/state, status messages, compatibility with selected assistive technologies |

Map findings to exact criteria only after checking the normative text. Conformance applies to complete pages and processes, not isolated passing components.
