# Operational dashboard review scenario

Use a synthetic incident-operations fixture with:

- current, delayed, missing, partial, zero, and unavailable metrics;
- negative and very large values;
- multiple timezones and a daylight-saving boundary;
- long service names and localized labels;
- active filters with zero results;
- backend timeout, rate limit, partial response, and stale-cache states;
- restricted rows and disabled export permission.

Review the primary operator decision, exception hierarchy, exact-value access, filter reversibility, provenance, keyboard flow, accessible summaries, responsive density, console/network behavior, and recovery.
