# GraphQL adapter

- Detect the released schema and client/tooling versions.
- Validate operation documents, fragments, variables, aliases, nullability, deprecated fields, unions, interfaces, custom scalars, directives, and error paths.
- Cover responses with both `data` and `errors`.
- Preserve unknown union/interface members and enum values safely.
- Verify persisted-operation behavior, cache keys, pagination, optimistic updates, and invalidation when used.
- Test authentication, authorization, partial data, rate limits, timeouts, and subscription reconnect.
- Do not treat the working draft as the project's stable release unless explicitly selected.
