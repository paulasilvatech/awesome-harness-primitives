# Linux Operations Plugin

Diagnose and remediate Linux incidents across Arch, CentOS, Debian, and Fedora with distribution-correct package managers, systemd, journal analysis, security modules, and rollback discipline.

## Installation

```bash
copilot plugin install linux-operations@copilot-primitives
```

## What's Included

### Agents

| Agent | Description |
|-------|-------------|
| `arch-linux-expert` | Arch Linux specialist focused on pacman, rolling-release maintenance, and Arch-centric system administration workflows. |
| `centos-linux-expert` | CentOS (Stream/Legacy) Linux specialist focused on RHEL-compatible administration, yum/dnf workflows, and enterprise hardening. |
| `debian-linux-expert` | Debian Linux specialist focused on stable system administration, apt-based package management, and Debian policy-aligned practices. |
| `fedora-linux-expert` | Fedora (Red Hat family) Linux specialist focused on dnf, SELinux, and modern systemd-based workflows. |

### Skills

| Command | Description |
|---------|-------------|
| `/linux-operations:arch-linux-triage` | Diagnose and remediate Arch Linux incidents with pacman, systemd, journal analysis, rolling-release upgrade discipline, kernel awareness, and rollback practices. |
| `/linux-operations:centos-linux-triage` | Diagnose and remediate CentOS Linux incidents with RHEL-compatible systemd, journal, dnf/yum, SELinux, firewalld, and rollback practices. |
| `/linux-operations:debian-linux-triage` | Diagnose and remediate Debian Linux incidents with apt, dpkg, systemd, journal analysis, AppArmor-aware checks, firewall review, and rollback practices. |
| `/linux-operations:fedora-linux-triage` | Diagnose and remediate Fedora Linux incidents with dnf, systemd, journal analysis, SELinux, firewalld, release-upgrade awareness, and rollback practices. |
