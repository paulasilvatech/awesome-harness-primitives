# Platform Vendor Expertise Plugin

Apply vendor platform expertise for Drupal, Laravel, Pimcore, Salesforce, and Shopify development, including Shopify App Store review triage.

## Installation

```bash
copilot plugin install platform-vendor-expertise@copilot-primitives
```

## What's Included

### Agents

| Agent | Description |
|-------|-------------|
| `drupal-expert` | Expert Drupal development assistant for custom modules, entities, themes, services, configuration, security, performance, testing, and deployment. |
| `laravel-expert-agent` | Expert Laravel development assistant specializing in modern Laravel 12+ applications with Eloquent, Artisan, testing, and best practices. |
| `pimcore-expert` | Build and review Pimcore CMS, DAM, PIM, and E-Commerce solutions with Symfony conventions. |
| `salesforce-expert` | Provide expert Salesforce Platform guidance, including Apex Enterprise Patterns, LWC, integration, and Aura-to-LWC migration. Use for secure, scalable Salesforce solutions. |
| `shopify-expert` | Expert Shopify development assistant for themes, Liquid, Online Store 2.0, apps, APIs, checkout extensions, metafields, performance, and CLI workflows. |

### Skills

| Command | Description |
|---------|-------------|
| `/platform-vendor-expertise:shopify-review-triage` | Triage public Shopify App Store reviews into a P0-P3 product or support brief while preserving source links, first-pass labels, and human-check status. |
