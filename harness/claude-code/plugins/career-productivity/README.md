# Career Productivity Plugin

Support individual work output: impact and brag sheets, performance and peer reviews, job-search materials, daily preparation, professional emails, meeting minutes, LinkedIn posts, and exam preparation.

## Installation

```bash
copilot plugin install career-productivity@copilot-primitives
```

## What's Included

### Agents

| Agent | Description |
|-------|-------------|
| `interview-prep` | Technical interview coach for software engineers. Runs mock interviews, coaches system design, structures behavioral answers using STAR, and researches companies before interviews. |
| `linkedin-post-writer` | Draft and format compelling LinkedIn posts with Unicode bold/italic styling, visual separators, and engagement-optimized structure. Transforms raw content, technical material, images, or ideas into copy-paste-ready LinkedIn posts. |
| `reepl-linkedin` | LinkedIn content strategy agent for Reepl-powered post drafting, carousel planning, scheduling guidance, analytics review, and voice-profile alignment. |

### Skills

| Command | Description |
|---------|-------------|
| `/career-productivity:brag-sheet` | Turn vague work-history prompts into evidence-backed impact statements for performance reviews, self-reviews, promotion packets, weekly updates, status reports, and accomplishments. |
| `/career-productivity:daily-prep` | Prepare a structured HTML day-prep file for tomorrow or a requested date by pulling Outlook calendar details through WorkIQ, classifying meetings, detecting conflicts and day-fit issues, cross-referencing workspace tasks, finding learning and deep-work slots, and producing productivity recommendations. |
| `/career-productivity:email-drafter` | Draft and review professional emails that match the user's established writing style by analyzing recipient context, tone, greeting, structure, sign-off, and language patterns when WorkIQ is available, then saving markdown drafts. |
| `/career-productivity:exam-ready` | Prepare a student for an exam from provided study material and syllabus only. |
| `/career-productivity:linkedin-post-formatter` | Draft and format LinkedIn posts with Unicode bold, italic, bold-italic, separators, hooks, CTAs, hashtags, and plain-text layouts. |
| `/career-productivity:meeting-minutes` | Generate concise, actionable meeting minutes for short internal meetings from notes, transcripts, recordings, or agendas. |
| `/career-productivity:performance-review-writer` | Draft self-assessments, peer reviews, 360 reviews, upward feedback, annual reviews, mid-year reviews, and performance appraisals in the user's voice. |
| `/career-productivity:technical-job-search` | Help software engineers perform active job-search tasks: analyze job descriptions, tailor resumes, write concise cover letters, evaluate offers, and draft interview follow-ups. |
