# Diagram Authoring Plugin

Author technical diagrams as source files: draw.io mxGraph XML, Excalidraw JSON, PlantUML ASCII output, and D2 entity-relationship diagrams generated from Entity Framework Core models.

## Installation

```bash
copilot plugin install diagram-authoring@copilot-primitives
```

## What's Included

### Skills

| Command | Description |
|---------|-------------|
| `/diagram-authoring:draw-io-diagram-generator` | Use when creating, editing, or generating draw.io diagram files (.drawio, .drawio.svg, .drawio.png). Covers mxGraph XML authoring, shape libraries, style strings, flowcharts, system architecture, sequence diagrams, ER diagrams, UML class diagrams, network topology, layout strategy, the hediet.vscode-drawio VS Code extension, and the full agent workflow from request to a ready-to-open file. |
| `/diagram-authoring:efcore-d2-db-diagram` | Generates D2 entity-relationship diagrams from Entity Framework Core models by extracting DbContext, DbSet<T>, entity configuration, migrations, keys, foreign keys, owned types, many-to-many joins, indexes, schemas, and technical tables. |
| `/diagram-authoring:excalidraw-diagram-generator` | Generate valid .excalidraw JSON diagrams from natural language descriptions, including flowcharts, relationship diagrams, mind maps, architecture diagrams, DFDs, swimlanes, class diagrams, sequence diagrams, and ER diagrams. |
| `/diagram-authoring:plantuml-ascii` | Generate ASCII art diagrams using PlantUML text mode. |
