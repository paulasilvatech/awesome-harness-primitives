# Claude API Reference Index

This package preserves imported provider guidance under `../shared/` and
language-specific examples under sibling language directories. The portable
`SKILL.md` is the entry point and selects only the references needed for the
active provider, language, and feature.

Use `../shared/live-sources.md` to locate current first-party documentation.
Treat cached model, price, limit, beta, and capability claims elsewhere in the
package as navigation aids until they are revalidated against those sources.

For Microsoft Foundry work, verify the exact Hosted on Azure model version,
subscription availability, quota, identity, and feature support before using a
cached example.
