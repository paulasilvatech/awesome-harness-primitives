# SIFAP system profile

SIFAP is the workshop's Payment Inspection and Administration System. The source system uses
Natural and Adabas and is being modernized through evidence-backed, behavior-preserving slices.

The historical workshop profile describes a 29-year-old system with 24 Natural members, four DDMs,
and one FDT listing. Treat those counts as a workshop fixture only after confirming them in the
target repository; they are not universal SIFAP facts.

The domain includes regulated identifiers and financial values. CPF, benefit amounts, credentials,
tokens, and production records are sensitive. Inspect only the minimum necessary evidence and mask
values in outputs, logs, examples, issues, and pull-request text.

Modernization preserves confirmed business outcomes rather than translating Natural syntax line by
line. Unknown business meaning remains an open question for a domain owner.
