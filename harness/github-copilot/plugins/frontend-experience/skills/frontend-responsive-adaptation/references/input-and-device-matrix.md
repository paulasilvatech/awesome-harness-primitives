# Input and device matrix

| Input or setting | Verify |
| --- | --- |
| Keyboard | Logical order, visible focus, completion, shortcuts, Escape, no traps |
| Touch | Target size, cancellation, scroll, virtual keyboard, gesture alternatives |
| Pointer | Precise controls, hover only as enhancement, cancellation, drag alternative |
| Screen reader | Names, roles, values, reading order, live updates, route and error announcements |
| Zoom/dynamic type | Reflow, readable measure, no clipping or hidden actions |
| Reduced motion | Equivalent state and hierarchy without required animation |
| Forced colors/high contrast | Visible content, focus, controls, status, charts |
| Locale/RTL | Expansion, mirrored flow where appropriate, numbers, dates, currency, icons |
