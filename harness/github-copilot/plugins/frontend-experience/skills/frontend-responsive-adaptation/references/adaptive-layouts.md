# Adaptive layout profiles

| Profile | Required considerations |
| --- | --- |
| Mobile browser | Dynamic browser chrome, safe areas, touch, virtual keyboard, portrait/landscape, slow network, installability when PWA applies |
| Tablet | Intermediate density, split views, panes, orientation, touch plus keyboard |
| Desktop browser | Resizable windows, pointer plus keyboard, efficient density, wide-screen measure, hover as enhancement |
| Native mobile | Native navigation, access prompts, lifecycle, deep links, offline sync, dynamic type, VoiceOver or TalkBack |
| Desktop app | Minimum and restored window sizes, menus, shortcuts, dialogs, multiple windows, offline and update states |
| Foldable/dual-screen | Posture, hinges, discontinuous regions, continuity across configuration changes |

For each transition, decide what stays, moves, summarizes, collapses, becomes modal, changes control, or becomes unavailable with an explanation.
