# Device matrix

Select by user population, business risk, framework support, OS distribution, input mode, accessibility settings, hardware capability, and reported defects.

| Tier | Evidence |
| --- | --- |
| Required | Every release for primary supported OS/device/window profile |
| Representative | Selected sizes, architectures, OS versions, and input combinations |
| Boundary | Minimum/maximum supported window, font scale, orientation, memory, network, or OS version |
| Incident | Exact environment for a reported defect |
| Advisory | Guidance only; no runtime or pilot evidence |

Record what each row proves. A successful simulator or one desktop OS does not prove real hardware or another platform.
