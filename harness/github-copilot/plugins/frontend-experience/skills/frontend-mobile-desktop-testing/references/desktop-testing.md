# Desktop testing

- Window: create, resize, minimum, maximize, fullscreen, restore, multi-window, display change.
- Navigation: menus, shortcuts, command palette, context menus, focus between windows.
- Native UI: file/folder picker, dialogs, notifications, tray/dock, drag/drop with alternatives.
- Security: renderer isolation, IPC validation, file and protocol handling, external links, updates.
- Data: offline, local persistence, migration, conflicts, interrupted writes, cleanup.
- Packaging: signed/unsigned policy, installer, architecture, auto-update, rollback, first run.
- Accessibility: screen reader, keyboard, high contrast, scaling, reduced motion, native and web-shell boundaries.

Test packaged builds for behavior that development mode cannot prove.
