# Streaming chat review scenario

Use synthetic content and exercise:

- new and restored conversations, long history, rename, archive, search, and deletion;
- empty, multiline, attachment, offline, sending, and retained-draft composer states;
- delayed acknowledgement, streaming, stop, completed, partial, failed, reconnect, duplicate event, and retry;
- proposed, approval-required, running, partial, completed, failed, denied, and cancelled tool activity;
- valid, missing, malformed, and restricted citations;
- code, table, long localized content, RTL text, unsafe HTML, suspicious links, and attachments;
- keyboard navigation, focus stability, live announcements, reduced updates, selection, and copying.

Record console/network errors, event ordering, correlation identifiers without secrets, and exact recovery behavior.
