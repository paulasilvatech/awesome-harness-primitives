# Public content review scenario

Review a synthetic site with:

- one public canonical article, one locale alternate, one paginated collection, one redirect, and one not-found page;
- authenticated account and billing routes;
- preview/staging deployment;
- visible event content eligible for a documented structured-data type;
- social preview with an absolute image URL and alternative text;
- Web App Manifest plus scalable and bitmap icons.

Verify rendered metadata, status codes, canonical and locale relationships, sitemap eligibility, private/preview indexing policy, structured-data truthfulness, asset dimensions, manifest alignment, and absence of ranking or rich-result guarantees.
