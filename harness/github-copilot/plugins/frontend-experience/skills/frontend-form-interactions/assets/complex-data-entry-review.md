# Complex data-entry review scenario

Use a synthetic multi-step account or order workflow with:

- optional and required fields, conditional sections, server cross-field validation, and an expired session;
- autofill, paste, international names and addresses, long text, locale-specific number/date input, and RTL content;
- mobile virtual keyboard, rotation, backward navigation, saved draft, and resumed session;
- duplicate submit, timeout with uncertain outcome, conflict, rate limit, offline, retry, and success;
- upload progress, rejection, cancellation, processing, and removal;
- destructive cancellation or reset with explicit consequence.

Verify preserved values, error associations and summary, focus and announcements, progress, idempotency evidence, safe recovery, and no secret or personal fixture data.
