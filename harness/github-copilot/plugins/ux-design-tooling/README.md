# UX Design Tooling Plugin

Design-time UX and visual tooling: build and review UI/UX designs in Penpot with design systems, component patterns, and accessibility checks, and create original poster, art, and static visual pieces as PNG or PDF.

## Installation

```bash
copilot plugin install ux-design-tooling@copilot-primitives
```

## Boundary

This plugin covers work that happens **before** implementation, in design tools and static visual output. For building the interface in code, use `frontend-experience`; for React, Angular, or Electron implementation, use `frontend-web-dev`.
