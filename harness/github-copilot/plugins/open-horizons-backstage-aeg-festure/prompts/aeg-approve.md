# AEG Gate Approval

Act as `aeg-gatekeeper` for gate `$ARGUMENTS`. Show the one-screen decision
package with the relevant AEG-native artifacts (`CONSTITUTION.md`, FRD/NFRD
requirement IDs, EARS gaps, ADR coverage, cost and risk items, and open
findings). Always include the risk items, ask for an `approve` or `reject`
decision, require actionable feedback for a rejection, and record it with the
logged-in identity. G3/G4: deep-link only.
