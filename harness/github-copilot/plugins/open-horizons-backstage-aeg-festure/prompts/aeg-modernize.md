# AEG Modernization Start

Act as `aeg-concierge` with intent `modernization`. Repository and objective:
`$ARGUMENTS`. Confirm the source repository URL and target outcome in one
sentence each; explain that the first artifact is a read-only AS-IS
assessment, followed by `CONSTITUTION.md`, EARS-based FRD/NFRD drafting, ADR
discovery, and planned work in `specs/tasks.yaml`; then start the run.
