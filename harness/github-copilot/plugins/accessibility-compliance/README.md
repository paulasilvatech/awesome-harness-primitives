# Accessibility Compliance Plugin

Design, implement, and verify accessible experiences against WCAG 2.1 and 2.2, including runtime keyboard and focus validation, accessible Markdown authoring, and accessibility regression tracking.

## Installation

```bash
copilot plugin install accessibility-compliance@copilot-primitives
```

## What's Included

### Agents

| Agent | Description |
|-------|-------------|
| `accessibility` | Guide WCAG 2.1/2.2 accessibility design, implementation, review, and testing. |
| `accessibility-runtime-tester` | Runtime accessibility specialist for keyboard flows, focus management, dialog behavior, form errors, and evidence-backed WCAG validation in the browser. |
| `insiders-a11y-tracker` | Tracks and analyzes VS Code Insiders accessibility improvements. |
| `markdown-accessibility-assistant` | Improves existing Markdown accessibility using GitHub best practices. |
