# Mcp Development Plugin

Build, test, secure, and release Model Context Protocol servers and clients, including CLI exploration, configuration auditing, implementation security review, pre-release QA, and making web apps agent-ready.

## Installation

```bash
copilot plugin install mcp-development@copilot-primitives
```

## What's Included

### Agents

| Agent | Description |
|-------|-------------|
| `csharp-mcp-expert` | Expert assistant for developing Model Context Protocol (MCP) servers in C#. Use for SDK design, tools, prompts, resources, testing, and debugging. |

### Skills

| Command | Description |
|---------|-------------|
| `/mcp-development:dotnet-mcp-builder` | Build and debug C#/.NET MCP servers and clients with current ModelContextProtocol 2.x packages. |
| `/mcp-development:mcp-builder` | Guide for creating high-quality MCP (Model Context Protocol) servers that enable LLMs to interact with external services through well-designed tools. |
| `/mcp-development:mcp-cli` | Use the MCP CLI to discover Model Context Protocol servers, inspect tool schemas, grep tool names, and call MCP tools with JSON, raw text, or stdin arguments. |
| `/mcp-development:mcp-implementation-security-review` | Review MCP server, client, and tool-handler source code for security. |
| `/mcp-development:mcp-release-qa` | Verify an MCP server before release by exercising a real protocol session, comparing runtime capabilities with source and documentation, testing failure paths, and recording reproducible evidence. |
| `/mcp-development:mcp-security-audit` | Audits MCP server configurations such as .mcp.json for hardcoded secrets, dangerous shell patterns, unpinned dependencies, unsafe npx usage, unapproved servers, and governance risks. |
| `/mcp-development:webmcpify` | Make a web app agent-ready with WebMCP by detecting app actions, building a manifest, integrating document.modelContext tools, verifying in a real browser, healing failures, and auditing diffs. |
