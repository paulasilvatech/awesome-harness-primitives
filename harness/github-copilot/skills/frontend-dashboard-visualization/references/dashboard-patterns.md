# Dashboard patterns

## Operational

Prioritize current status, exceptions, ownership, freshness, exact values, and fast repeated action. Preserve dense scanning and clear severity without turning every value into a card.

## Analytical

Prioritize the question, comparison context, filters, explanation, provenance, drilldown, and uncertainty. Keep global and local filters distinct.

## Executive

Use only evidence-backed metrics with definitions, trends, comparison windows, and owners. Avoid filler KPIs and unsupported summaries.

## Interaction

- Keep filters visible, reversible, and reflected in titles or URLs where appropriate.
- Preserve state across navigation only when the product convention supports it.
- Make refresh, stale data, delayed data, and last-updated behavior explicit.
- Define selection, hover, keyboard, drilldown, reset, and empty-result behavior.
