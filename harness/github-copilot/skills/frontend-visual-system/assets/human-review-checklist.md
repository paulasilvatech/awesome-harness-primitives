# Visual system human review

Use `pass`, `needs revision`, `blocked`, or `not applicable`.

| Area | Observable question | Status | Evidence / revision |
| --- | --- | --- | --- |
| Product fit | Do hierarchy, density, typography, imagery, and motion reflect the actual product job and trust context? |  |  |
| System integrity | Are existing semantic tokens and components reused before additions? |  |  |
| Typography | Do roles remain readable with long, localized, resized, and fallback text? |  |  |
| Color | Is meaning preserved without color across themes, focus, status, charts, and contrast modes? |  |  |
| Layout | Are cards and containers justified, stable, and free of nested ornamental framing? |  |  |
| Motion | Does motion communicate state and have a reduced-motion path? |  |  |
| Specificity | Would the result still identify this product after removing the logo? |  |  |
