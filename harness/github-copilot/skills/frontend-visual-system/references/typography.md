# Typography decision record

Record:

- installed or brand typefaces and available weights;
- language and character coverage;
- semantic roles such as display, heading, body, label, code, data, and caption;
- bounded sizes, line heights, measures, and responsive behavior;
- loading and fallback strategy;
- long words, localization expansion, zoom, text spacing, and dynamic type behavior.

Prefer semantic roles over component-specific values. Do not set letter spacing or fluid scaling without typeface and content evidence.
