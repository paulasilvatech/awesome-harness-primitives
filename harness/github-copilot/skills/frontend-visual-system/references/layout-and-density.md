# Layout and density

| Product surface | Typical priority |
| --- | --- |
| Marketing or editorial | Narrative order, readable measure, meaningful media, clear conversion path |
| Operational | Dense scanning, status, exception handling, efficient repeated actions |
| Analytical | Question, filters, comparison, provenance, exact values, drilldown |
| Transactional | Progress, data entry, validation, confirmation, recovery |
| Creative | Workspace, tools, canvas, selection, undo, asset state |

Use page regions before cards. Keep primary controls visible, define stable sizes for content that loads asynchronously, and test real long content. Density is a workflow decision, not a universal preference.
