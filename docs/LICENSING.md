# Licensing and provenance

This repository aggregates original work and content derived from multiple upstream projects. A public repository does not imply that every file shares one license.

## Determine the applicable license

Use this order:

1. A `LICENSE` or `LICENSE.txt` inside the plugin or skill package.
2. The plugin manifest's `license` field.
3. `THIRD_PARTY_NOTICES.md`, `NOTICE`, or `PROVENANCE.json`.
4. The upstream repository and commit recorded in `harness/github-copilot/manifests/plugin-sources.json`.

When none of those sources grants a license, treat the content as not licensed for reuse beyond what applicable law permits.

## Generated copies

Generated Claude Code content and plugin-local copies retain the license and provenance of their canonical or upstream source. Conversion does not relicense content.

## Before redistribution

- Review the exact package's license and notices.
- Preserve attribution and third-party notices.
- Do not assume a plugin manifest's license covers unrelated packages.
- Consult qualified legal counsel for compliance questions.
