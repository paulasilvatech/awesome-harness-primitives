# Canvas design

Create an original visual philosophy from the user's subtle brief, then express it as a highly crafted static `.png` or `.pdf` artwork plus the `.md` philosophy that guided it.

## When to invoke

- "Create a poster for this idea."
- "Make a static piece of visual art as a PNG."
- "Design a sophisticated PDF canvas."
- "Create a visual philosophy and express it."
- "Make this pristine enough for a museum display."

## Prerequisites and context

- Output only `.md`, `.pdf`, and `.png` files.
- Create original designs; never copy existing artists' work or protected visual styles.
- Search `./canvas-fonts` before choosing fonts. Bundled font license files include `canvas-fonts/ArsenalSC-OFL.txt`, `canvas-fonts/BigShoulders-OFL.txt`, and `canvas-fonts/BricolageGrotesque-OFL.txt`.
- Download and use additional fonts only when needed for the user's request and licensing permits it.

## Design philosophy

Create a visual philosophy, not a layout template. Treat the user's brief as foundation rather than a constraint, and invent an aesthetic movement that can be interpreted through form, space, color, composition, images, graphics, shapes, patterns, and minimal text.

| Element | Requirement |
| --- | --- |
| Movement name | Use 1-2 words, such as `Brutalist Joy`, `Chromatic Silence`, or `Metabolist Dreams`. |
| Philosophy length | Write 4-6 concise but complete paragraphs. |
| Visual dimensions | Address space and form, color and material, scale and rhythm, composition and balance, and visual hierarchy. |
| Text stance | Emphasize sparse, essential-only text integrated as a visual element. Never rely on paragraphs inside the artwork. |
| Craftsmanship | Repeatedly stress master-level execution, painstaking attention, deep expertise, and work that appears labored over for countless hours. |
| Creative room | Be specific about aesthetic direction while leaving interpretive space for the canvas phase. |

Condensed philosophy examples to emulate in spirit, not copy:

| Movement | Visual expression |
| --- | --- |
| `Concrete Poetry` | Monumental form, bold geometry, sculptural typography, Brutalist spatial divisions, Polish poster energy, and precise placement. |
| `Chromatic Language` | Color as information system, geometric precision, small labels, chromatic fields, and painstaking calibration. |
| `Analog Meditation` | Paper grain, ink bleeds, negative space, photography or illustration, whispered typography, and meditative balance. |
| `Organic Systems` | Rounded forms, organic clustering, nature-derived color, diagrams, iconography, and expert spatial orchestration. |
| `Geometric Silence` | Grid precision, bold photography or stark graphics, dramatic negative space, Swiss formalism, and refined alignment. |

## Subtle reference

Before creating the canvas, identify the subtle conceptual thread from the original request. The reference should be niche and embedded inside the art, not literal or announced. Someone familiar with the subject should feel it intuitively, while others experience a masterful abstract composition. Think like a jazz musician quoting another song: only those who know will catch it, but everyone should appreciate the composition.

## Canvas creation

Express the philosophy and subtle reference as one single-page, highly visual, design-forward `.pdf` or `.png` unless the user asks for more pages. The final work should be 90% visual design and 10% essential text.

| Design rule | Direction |
| --- | --- |
| Sophistication | Even when the brief references a movie, game, or book, make art rather than something cartoony or amateur. |
| Visual language | Use repeating patterns, perfect shapes, systematic marks, layered accumulation, and analytical reference markers when they strengthen the concept. |
| Typography | Keep text minimal and visual-first. Thin fonts usually work, but context may justify bold gestures. Use different fonts when writing text. |
| Boundaries | Nothing may fall off the page or overlap unintentionally. Maintain margins, breathing room, and clear separation. |
| Craft | Make the result look like it took countless hours by someone at the top of their field. Double-check spacing, color, typography, and formatting. |
| Refinement | On the second pass, polish what exists instead of adding more graphics. Ask: "How can I make what's already here more of a piece of art?" |

For multi-page requests, create distinct pages that share the same philosophy while telling a tasteful visual story. Bundle pages in one `.pdf` or as multiple `.png` files.

## Procedure

1. Create the design philosophy as a `.md` file.
2. Deduce and record the subtle conceptual reference.
3. Create the canvas as a `.pdf` or `.png` using the philosophy.
4. Take a second pass for pristine craftsmanship: refine alignment, spacing, containment, color, and typography without adding unnecessary elements.
5. Deliver the philosophy file and final visual artifact.

## Limits

- Do not copy existing artists' work or produce a protected style imitation.
- Do not produce interactive applications, videos, or dynamic documents through this skill.
- Do not turn the artwork into a text-heavy document with decoration.

## Source workflow emphases

Preserve the original workflow emphases as operating labels: DESIGN PHILOSOPHY CREATION, THE CRITICAL UNDERSTANDING, HOW TO GENERATE A VISUAL PHILOSOPHY, PHILOSOPHY EXAMPLES, ESSENTIAL PRINCIPLES, DEDUCING THE SUBTLE REFERENCE, CANVAS CREATION, FINAL STEP, and MULTI-PAGE OPTION. The philosophy/aesthetic movement is CREATED first, then EXPRESSED and EXPRESSES the subtle REFERENCE VISUALLY. Keep ARTISTIC FREEDOM, PURE DESIGN, SPATIAL EXPRESSION, VISUAL EXPRESSION, MINIMAL TEXT, ESSENTIAL PRINCIPLE, EXPERT CRAFTSMANSHIP, CRITICAL GUIDELINES, PURE DESIGN OBJECTS, repeated craftsmanship stressed REPEATEDLY, and expert-level human-crafted refinement as non-negotiable constraints. Treat movie/game/book briefs with sophistication. Use whisper-quiet sans-serif labels only when they fit, preserve observation-dense systems, and when instinct/intuition suggests adding clutter, STOP to refine/polish instead. The user ALREADY said the work MUST be pristine; this is VERY IMPORTANT and CRITICAL.

## Output template

```markdown
## Canvas design result

**Status:** complete | blocked
**Philosophy file:** `<path>.md`
**Canvas file:** `<path>.png` or `<path>.pdf`
**Movement:** `<1-2 word movement name>`

### Subtle reference
<one concise sentence describing the embedded conceptual thread>

### Craft pass
- Composition containment: pass | fail
- Typography and font choice: pass | fail
- Margins and overlap check: pass | fail
- Second-pass refinement completed: pass | fail
```

## Quality gate

- [ ] A `.md` philosophy file and a `.png` or `.pdf` canvas file were created.
- [ ] The philosophy has a 1-2 word movement name and 4-6 paragraphs.
- [ ] The artwork is overwhelmingly visual, with minimal essential text only.
- [ ] The subtle reference is embedded rather than literal or announced.
- [ ] Fonts were selected intentionally, with `./canvas-fonts` checked when available.
- [ ] Nothing falls off the page, overlaps unintentionally, or lacks margins.
- [ ] A second refinement pass improved craftsmanship without cluttering the design.
- [ ] The work is original and does not copy an existing artist's protected expression.
